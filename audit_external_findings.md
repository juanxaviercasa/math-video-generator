# Hallazgos externos para la auditoría

Fecha de revisión: 2026-08-16.

## Manim Community
La web oficial describe Manim como una biblioteca Python mantenida por la comunidad para crear animaciones matemáticas. Muestra ejemplos con LaTeX, MathTex, transformaciones, planos y funciones no lineales, y señala que es software libre y de código abierto bajo licencia MIT. Esto confirma que Manim es un motor potente de render programático, pero no es por sí mismo un producto terminado para usuarios no técnicos.

Fuente: https://www.manim.community/

## MathGPT
La página de creación de videos muestra un flujo web orientado a escribir un concepto STEM y crear un video explicativo. También presenta galería de videos, historial de chats, práctica de exámenes, acceso para usuarios y una oferta de suscripción. Esto evidencia que la expectativa competitiva no se limita a generar un MP4: incluye historial, biblioteca, cuentas, aprendizaje recurrente y monetización integrada.

Fuente: https://math-gpt.org/tools/video

## NoteGPT
La página ofrece generar lecciones matemáticas paso a paso a partir de una pregunta, permite introducir texto, cargar una imagen o PDF, y presenta ejemplos para matemáticas, física y química. Esto eleva la expectativa de entrada multimodal y de cobertura STEM, frente al repositorio auditado que solo acepta título y texto en un formulario local.

Fuente: https://notegpt.io/ai-math-video-generator

## Implicación para el repositorio
El diferencial más defendible no debería ser únicamente “usa IA + Manim”, porque el mercado ya comunica videos explicativos generados desde conceptos matemáticos. La oportunidad está en una experiencia verificable y pedagógica: solución matemática validada, escenas editables, controles del docente, accesibilidad, reutilización en clases y exportación/compartición confiable.
