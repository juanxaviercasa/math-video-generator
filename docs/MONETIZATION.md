**$29.99 Pro:**

- Comparable con Skillshare/Udemy (precio docente)

**$79.99 Team:**

**Enterprise Custom:**

- Volumen: 50+ usuarios
- Support 24/7 incluido

## 🔑 Key Metrics

### KPIs a Monitorear

1. **CAC** (Customer Acquisition Cost)
   - Objetivo: < $20 para Pro
   - Métrica: Total marketing spend / nuevos clientes

2. **LTV** (Lifetime Value)
   - Objetivo: > $300 para Pro (10 meses)
   - Métrica: ARPU × Average customer lifetime

3. **Churn Rate**
   - Objetivo: < 5% mes
   - Métrica: Clientes perdidos / Clientes activos

4. **Conversion Rate**
   - Objetivo: 2% Free → Pro
   - Métrica: Pro signups / Free users
