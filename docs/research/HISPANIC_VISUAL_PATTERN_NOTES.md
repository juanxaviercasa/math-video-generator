# Notas de inspección visual y pedagógica del corpus hispanohablante

## Alcance y cautela

Se inspeccionaron diez videos públicos mediante un protocolo común de análisis audiovisual: hook, promesa, presencia humana, pizarra o interfaz, fórmulas, permanencia, sustitución, pausas, voz, transiciones, comprobación y cierre. Los análisis multimodales permiten formular hipótesis visuales y temporales, pero no sustituyen los datos privados de retención de YouTube Analytics. Los rangos temporales deben tratarse como observaciones aproximadas del video inspeccionado.

## Patrones que aparecen en varios canales

La **permanencia de la referencia** es el patrón más repetido y más directamente transferible. JulioProfe, Daniel Carrión, Profe Alex, Profesor10demates, unicoos, Matemáticas con Juan, Khan Academy y Tareasplus mantienen de alguna forma el enunciado, la fórmula o la función base mientras ejecutan el paso actual. La razón pedagógica es que el estudiante no necesita reconstruir la estructura desde la memoria de trabajo.

La **codificación semántica del color** aparece con distintos estilos, pero la regla común es estable: el color debe representar una relación y no decorar. Las variables, las ecuaciones del sistema, la función y su curva, o las premisas de un problema deben conservar el mismo color cuando reaparecen. El producto debe guardar tokens de color por entidad matemática, no por escena aislada.

La **secuencia humana recurrente** no es “fórmula → resultado”, sino contexto, identificación, operación, simplificación, interpretación y comprobación. En problemas verbales se observa con claridad la secuencia `definir → plantear → resolver → responder → comprobar`; en funciones aparece como `entrada → regla → salida → gráfica`; en álgebra, como `referencia → paréntesis vacíos → sustitución → simplificación`.

La **pausa útil** no es silencio accidental. Puede ser una pausa predictiva explícita, como en Khan Academy y Profe Alex; una pausa dramática para enfatizar un error, como en Profesor10demates; o una breve detención antes de un resultado. Para el generador, cada pausa debe tener propósito, prompt, duración y evento posterior, y no debe dejar la pantalla vacía.

El **ritmo humano** combina tramos. Los conceptos y las advertencias se explican más despacio; la aritmética mecánica puede acelerarse; el resultado y la comprobación reciben un tiempo de lectura adicional. El error del producto sería usar una duración uniforme por evento. La duración debe depender del tipo de operación, la complejidad visual y la importancia pedagógica.

La **comprobación** es una frontera entre resolver y enseñar a confiar en la solución. Aparece como sustitución en la ecuación, calculadora, gráfica, botón de feedback o revisión del enunciado. Debe ser una escena explícita y no una frase final comprimida.

## Patrones que no deben copiarse literalmente

La pizarra saturada de Derivando funciona como atmósfera de divulgación, pero no como lienzo para una derivación. La introducción larga de un directo de JulioProfe sirve para comunidad, pero no debe trasladarse a un video corto generado automáticamente. El ritmo extremo de Matemáticas con Juan funciona como clase panorámica o repaso, no como plantilla para un primer aprendizaje. El avatar y los sonidos de Daniel Carrión pueden inspirar energía, pero el producto debe conservar una identidad propia.

## Hipótesis de implementación

El generador debería modelar tres capas simultáneas: una **capa persistente** con la fórmula o problema, una **capa de operación** con el microevento actual y una **capa de orientación** con etiqueta, color, flecha, cursor simulado o prompt. El evento debe declarar cuál capa cambia y cuáles permanecen.

El timeline debería admitir por lo menos cinco tipos de pausa: `predict` antes de revelar, `notice` para señalar un signo o término, `write` para dar tiempo de copia, `check` para verificar y `reflect` para resumir. Cada tipo necesita una duración base configurable y una regla de no-vacío visual.

El storyboard debería reservar una región fija para referencia, una región de trabajo y una región de comprobación. En 9:16 estas regiones deben apilarse, no reducirse hasta volver ilegible la fórmula. En 1:1 la tabla o gráfica debe competir con la ecuación solo después de que la sustitución esté consolidada.
